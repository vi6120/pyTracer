The real problem

A green test does not mean your fix worked.

Agents are nondeterministic. Re-run a failed one and the model and tool responses come back different every time, so when a test turns green you cannot tell whether your code change fixed it or the model just drifted.

Meet pyTracer

The regression-testing layer for AI agents.

Capture a real run once, freeze its model and tool responses, and replay it anywhere, deterministically. The same failure reproduces byte for byte.

capture

Captured from real runs

Record exactly what your agent did, down to each model call and tool result, with the branch and commit stamped on it.

freeze

Frozen and deterministic

Replay injects the recorded responses, so a run reproduces identically with no live model calls and no flakiness.

reproduce

Reproduced on any branch

Re-run a captured failure on a fix branch and get a fixed / still-failing / diverged verdict per scenario.

The replay engine

One captured run, replayed three ways.

Choose how much to hold frozen: full (recorded model and tools), partial (recorded tools, live model), or live (re-run everything). Every mode adds assertions, run diffing, a failure fingerprint, and a three-way outcome classifier. Replay stays faithful on real agents: streaming responses and concurrent or repeated tool calls replay in order, the clock is frozen and the RNG seeded, and side-effects are detected.

FAQ

Questions, answered.

Still curious? The docs go deeper, open an issue on GitHub, or email services@pytracer.com.

How is pyTracer different from tracing or eval tools?
Tracing shows you that a run happened; eval scores an output. pyTracer freezes a captured run and re-runs it deterministically on another branch, so you learn whether your code change is what fixed the failure, not just that today's run passed. See the full comparison.
What does deterministic replay actually mean?
The recorded model and tool responses are injected back in during replay, so the agent follows the exact same path with no live API calls. The same failure reproduces identically every time.
Do I have to change my agent code?
Add the @op decorator to the functions that call models and tools. One or two lines each, and it does not change their behavior.
Which frameworks are supported?
LangGraph, CrewAI, AutoGen, and the OpenAI Agents SDK have dedicated adapters, and any Python agent works once you instrument it by hand.
Is it open source? What license?
Yes. The client toolchain is Apache-2.0 and the hosted server components are AGPL-3.0. All 12 packages are on PyPI and the repository is public.
Can I self-host, or is there a hosted option?
Both. Self-host the gateway and stores as a Docker stack behind a TLS reverse proxy, or point the SDK at the live gateway at gateway.pytracer.com.
Does my prompt data leave my machine?
Only the spans you capture are sent to the gateway you configure, which can be your own. You control what is instrumented and where it goes.
