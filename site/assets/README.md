# Site assets

Place the pyTracer logo here as **`logo.png`**. It is used by:

- the site hero (`/assets/logo.png`)
- the browser-tab favicon on every page
- the repository README

For best results save a **trimmed** PNG (cropped to the logo with minimal
surrounding whitespace), around 1000px wide or larger. A transparent background
also works well on both light and dark pages.
