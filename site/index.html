pyTracer captures what an agent does, replays a past run deterministically by injecting the recorded responses, and regression-tests it in CI. Its headline feature is cross-branch reproduction: take a captured failure and re-run it on another branch with the model and tool responses held frozen, so you learn whether a branch actually fixed the bug.

How a team uses it

Instrument once, turn failures into tests, then gate your branches on them.

STEP 1

Instrument your agent

Add the @op decorator to the functions that call models and tools. One or two lines each, and it does not change their behavior.

STEP 2

Turn a failure into a test

Browse captured runs and scaffold a runnable test collection from a failing one. Replays are deterministic and touch no live services.

STEP 3

Gate branches in CI

Run the collection on every pull request, comment the results, and reproduce a failure on any branch to confirm a fix.

Install

One package pulls in the whole platform, or install just the SDK in your agent.

# the whole platform
pip install pytracer-all
# or just the SDK
pip install pytracer-sdk

All 12 packages are on PyPI - see the full package list or open pytracer-all and pytracer-sdk directly. New here? Start with the step-by-step user guide.
